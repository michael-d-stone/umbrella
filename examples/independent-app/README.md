# Independent application declaration

This is a declaration-only example for an independently maintained notes application, not an implemented application. Its illustrative read capability is advertised metadata, not a working endpoint or permission grant.

Copy the manifest into a directory beside an existing application, change its module ID, name, and capability names, and scan that parent directory with Umbrella's discovery command. The application can live outside this repository and keep its storage and standalone workflow. No Umbrella source edits or project approval are necessary.
